# 🐉 Ryujin AI

An intelligent multi-agent AI platform built with **FastAPI**, **Streamlit**, and **LangGraph**.

Ryujin is designed to provide a seamless AI experience where users simply describe their task, and the system automatically selects the appropriate agents and tools behind the scenes.

> **Ask naturally. Ryujin handles the rest.**

---

## 🚀 Current Features

- ✨ Modern glassmorphism UI
- 🎨 Custom Ryujin theme
- 💬 Native Streamlit chat interface
- 📱 Responsive layout
- 🐉 Automatic agent orchestration concept
- ⚡ FastAPI backend foundation

---

## 🛠️ Tech Stack

- **Frontend:** Streamlit
- **Backend:** FastAPI
- **AI Framework:** LangGraph
- **Language:** Python
- **Database:** SQLite (Development)
